<!--
- No vamos a programar esto, solo entender qué rol cumple cada uno.
- HTML: la estructura, el contenido. "Hay un título, una lista, un botón".
- CSS: la apariencia. Colores, tamaños, posiciones.
- JavaScript: el comportamiento. Es un lenguaje de programación que corre DENTRO del navegador. Reacciona a eventos: clics, teclas, scroll.
- Analogía de la casa: HTML son las paredes, CSS la pintura y los muebles, JS la instalación eléctrica (apretás un botón y pasa algo).
- Clave: con JavaScript, el navegador deja de ser un simple "dibujante de HTML" y puede ejecutar lógica. Esto abre la puerta a lo que sigue.
